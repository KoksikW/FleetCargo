# Fleet & Cargo

**Fleet & Cargo** – настільний застосунок для Windows для обліку автопарку, водіїв і вантажів, планування рейсів та контролю доступності ресурсів у логістичній компанії.

Проєкт виконано в межах курсової роботи «Fleet & Cargo – логістична система управління автопарком та маршрутами».

## Можливості

- **Автопарк** – облік автомобілів: державний номер, марка, модель, пробіг, дати наступного ТО та закінчення страхування, статус («Вільний» / «В дорозі»), фото та характеристики.
- **Водії** – облік водіїв: прізвище, ім’я, телефон, статус, фото.
- **Рейси** – створення рейсу із зазначенням автомобіля, водія, пунктів відправлення та призначення, вантажу й дат; завершення рейсу.
- **Звіти** – зведені звіти та експорт даних у Excel.
- **Контроль ресурсів** – заборона призначення на новий рейс автомобіля чи водія зі статусом «В дорозі».
- **Перевірка доступності на дати** – SQL-вибірка, що виявляє перетин періодів рейсів.
- **Попередження про ТО та страхування** – кольорове виділення автомобілів, у яких термін минув або наближається.
- **Пошук і фільтрація** записів у модулях.
- **Експорт у Excel** – маршрутний лист водія та звіти у форматі `.xlsx` (без встановленого Microsoft Excel).
- **Налаштування інтерфейсу** – розмір вікна, вибрана вкладка й акцентний колір зберігаються між запусками у файлі XML.
- **Вікно «Авторство»** – відомості про автора проєкту.
- **Автоматична самоперевірка** – 19 перевірок шару доступу до даних і бізнес-логіки (сполучення клавіш `Ctrl+Shift+T`); виконуються в транзакції з відкатом, тому дані бази не змінюються.

## Технології

| Призначення | Засіб |
| --- | --- |
| Мова та платформа | C#, .NET 10 |
| Інтерфейс | WPF (XAML), TabControl |
| Архітектура | MVVM |
| База даних | SQLite (`Microsoft.Data.Sqlite`) |
| Експорт | ClosedXML |
| Середовище розробки | Microsoft Visual Studio |

## Вимоги

- Windows 10 або 11;
- Microsoft Visual Studio з робочим навантаженням «Розробка класичних програм .NET» (для збирання з вихідного коду);
- .NET 10 SDK (для збирання) або .NET 10 Desktop Runtime (для запуску зібраної програми).

Окремий сервер баз даних та Microsoft Excel не потрібні.

## Запуск

1. Клонуйте репозиторій:

   ```bash
   git clone <https://github.com/KoksikW/FleetCargo.git>
   ```

2. Відкрийте файл рішення (`.sln`) у Visual Studio.
3. Дочекайтеся відновлення NuGet-пакетів (`Microsoft.Data.Sqlite`, `ClosedXML`).
4. Запустіть проєкт (`F5`) або виконайте команду з каталогу проєкту:

   ```bash
   dotnet run
   ```

Під час першого запуску порожня база даних створюється автоматично та заповнюється тестовими даними (6 автомобілів, 5 водіїв, 5 типів і 6 вантажів, 2 рейси).

## Дані програми

Усі дані зберігаються локально в каталозі `%LocalAppData%\FleetCargo`:

| Файл / каталог | Призначення |
| --- | --- |
| `fleetcargo.db` | База даних SQLite |
| `settings.xml` | Налаштування інтерфейсу |
| `Photos\` | Копії вибраних користувачем зображень |

Щоб повернути програму до початкового стану, закрийте її та видаліть цей каталог.

## База даних

База складається з п’яти таблиць: `Vehicle`, `Driver`, `CargoType`, `Cargo`, `Trip`. Цілісність забезпечується первинними й зовнішніми ключами, обмеженнями `CHECK` та індексами; змінення кількох таблиць виконується в межах транзакцій.

## Структура проєкту

```text
FleetCargo/
├── App.xaml            – точка входу, підключення стилів
├── Resources/          – спільні стилі та ресурси інтерфейсу
├── Views/              – вікна й екрани модулів (MainWindow, VehiclesView, DriversView, TripsView, ReportsView)
├── ViewModels/         – моделі подання (шаблон MVVM)
├── Models/             – моделі даних
├── Data/               – доступ до БД: ініціалізація, UnitOfWork
│   └── Repositories/   – репозиторії (автомобілі, водії, вантажі, рейси)
└── Services/           – бізнес-логіка, експорт у Excel, налаштування
```

> Точні назви файлів і каталогів залежать від поточного стану репозиторію.
